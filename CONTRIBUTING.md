# Contributing to Care Heaven

First off, thank you for considering contributing to the Care Heaven Dental Clinic & Healthcare web application! It's people like you that make modern healthcare digital tools a great community resource.

## How Can I Contribute?

### Reporting Issues / Bugs
This section guides you through submitting an issue report. Following these guidelines helps maintainers understand your report, reproduce the behavior, and implement fixes smoothly:
* Use the repository Issues tab to report bugs.
* Describe the exact steps that reproduce the problem in detail.
* Specify browser type, version, and device used (desktop/tablet/mobile).
* Provide screenshots or console logs whenever applicable.

### Suggesting Enhancements & UI Improvements
* Use the Issues tab to suggest features or aesthetic enhancements.
* Provide a clear and descriptive title for the feature suggestion.
* Provide a breakdown of the suggested workflow (e.g., patient booking flow, admin filters, accessibility additions).
* Explain how this enhancement benefits patients or clinic administrators.

### Submitting Pull Requests
1. Fork the repo and create your branch from `main`.
2. Ensure any new React components or UI elements align with the clinic's color scheme, typography, and responsive design guidelines.
3. Test layout responsiveness across mobile, tablet, and desktop viewports.
4. Verify that appointment form validation rules remain robust.
5. Create a clean pull request with a descriptive title and summary of changes.

## Code & Style Guidelines
* **Commit Messages**: Use conventional commits (e.g., `feat: enhance appointment date picker`, `fix: mobile navigation menu toggle`).
* **JavaScript / React**: Use modern React patterns, clean component modularity, and readable JSX.
* **Styling**: Maintain consistent Tailwind CSS utility classes and pleasant visual contrast.

Thank you for helping improve Care Heaven!
