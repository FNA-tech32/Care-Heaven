# Security Policy

## Supported Versions

Currently, the latest version of the Care Heaven platform on the `main` branch is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

Security and patient data privacy are top priorities. If you discover a security vulnerability or potential data exposure within this application, please do not disclose it publicly.

Instead, please report it via:
* Direct contact to the clinic tech team at: `contact@careheaven.demo` (with subject `[Security Issue]`)
* Alternative emergency contact: `support@careheaven.demo`

We will triage the vulnerability and respond promptly (typically within 24 to 48 hours). If confirmed, a security patch will be deployed immediately.

Thank you for helping keep Care Heaven secure!
